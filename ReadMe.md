# Java Programming – From Basics to Advanced OOP

Welcome to the repository for my Java programming class exercises. This repository serves as a structured archive of my academic journey, documenting my progression from fundamental syntax to advanced Object-Oriented Programming (OOP) concepts and design patterns.

The goal of this repo is to maintain clean, well-documented, and executable code samples that showcase a deep understanding of Java's capabilities.

---

## 🚀 Learning Roadmap & Highlights

The exercises are categorized by complexity, capturing a full spectrum of Java development:

### 1. Fundamental Syntax & Structure (Basics)
*   Variables, data types, and operators.
*   Control flow statements (`if-else`, `switch-case`, `loops`).
*   Method definitions, basic arrays, and memory manipulation.

### 2. Intermediate OOP Foundations
*   **Encapsulation:** Class design, explicit constructors, access modifiers (`private`, `protected`, `public`), and data masking via getters/setters.
*   **Inheritance & Composition:** Building reusable class structures with the `extends` keyword and establishing dynamic object relationships.
*   **Polymorphism:** Compile-time (overloading) vs. Runtime (overriding) polymorphism.
*   **Abstraction:** Designing flexible architectures using `abstract` classes and `interface` specifications.

### 3. Advanced Java Components
*   **Exception Handling:** Custom exception design and structured error resilience using `try-catch-finally` blocks.
*   **Java Collections Framework:** Storing and manipulating data dynamically via `List`, `Set`, `Map`, and standard data structures.
*   **Generics:** Writing type-safe, reusable algorithms and classes.
*   **File I/O & Multithreading:** Working with data streams, local file systems, and managing parallel execution threads.
